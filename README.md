# GSI Claude Bernard — Prototype
Prototype non officiel prêt à ouvrir dans VS Code.

Fichiers :
- index.html
- style.css
- script.js
- assets/logo-cb.png

Ouvre le dossier dans VS Code puis lance index.html avec Live Preview / Live Server.
